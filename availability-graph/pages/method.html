How this evidence is produced

  1. Capture. availability-graph/scripts/capture_availability.py runs on a GitHub runner. It reads the official week schedule page, the official game centre page of every game, the official Game Book PDF it links to, the official NFL.com team roster page of all 32 clubs and the club depth-chart page each of those roster pages links to. Every response is hashed (SHA-256) and timestamped; the raw bytes are uploaded as a workflow artifact and are kept outside this site.
  2. Parse. The game-book reader is pinned by unit tests to the official rows of the New England Patriots at Detroit Lions game book (2026 REG 10), which was read first-hand: availability-graph/tests/test_capture_parse.py. A section that cannot be parsed is a failed capture, not a blank cell.
  3. Join. availability-graph/scripts/analyze.py joins the official starting lineups of two captured weeks, the official weekly injury report and the official roster status into the availability graph.
  4. Publish. availability-graph/scripts/build_site.py renders these pages from the committed registers, and availability-graph/scripts/verify.py fails the build if any table row loses its source link or if a register drifts from the published counts.

What this evidence cannot support yet

  • No depth tier. The depth-order source audit records what each club publishes; a tier is published only for a club whose official depth order is verified. Nothing is inferred from a jersey number, experience, salary or a roster listing.
  • No snap counts. A game book prints participation, not snaps. Snap counts are a separate official source (Next Gen Stats) and are not captured here.
  • One capture series. The registers hold the weeks that have been captured. The graph compares the earliest and the latest captured week, so the comparison window is a capture window, not a season.
  • Game Book reuse terms. The official Game Book carries a written notice that the summary and play-by-play are for assisting media coverage and that any other use needs the written permission of the NFL. The links are published; the reuse position is a decision for the owner and is flagged on the Flagged for review page.
