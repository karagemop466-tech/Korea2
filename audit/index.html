What the automated check covers

The offline checker inspects local HTML targets and anchors, checks recognized publisher links in static rows, and checks source IDs in the dynamic dashboard’s JSON. Broken targets and unreadable dashboard JSON fail the check; publisher/ID findings are nonblocking review flags by default. A strict option can fail on those flags. The checker does not render pages, fetch external sites, assess whether a citation supports a claim, reconcile NFL data, or validate a model.
