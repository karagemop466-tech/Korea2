Strategy Framework — Singles, Parlays, Player-Prop Combos

Each strategy below is a template that must pass every validation gate (G-1 … G-8) before it can be considered. Betting lines, odds, and player-prop prices are not published by the NFL or any official league source; all line/odds fields are therefore left blank and flagged unverified. Historical game results used for backtesting are from the verified source file.

Validation gates (all strategies must pass every gate)

GateRequirementSource / basis
G-1Edge after vig: |model probability − implied probability from line| ≥ edge threshold (default 4%).nfl_games.csv (elo_prob1) — line source: none (unverified)
G-2Minimum backtest sample: signal tested on ≥ 100 games from source data.nfl_games.csv (16,810 games, 1920–2020)
G-3Out-of-sample check: signal evaluated on seasons not used for tuning.Project methodology; data: nfl_games.csv
G-4Correlation disclosure: correlation between parlay legs estimated and payout adjusted; same-game legs require same-game correlation data.Correlations page — same-game data unavailable (unverified)
G-5Bankroll rule: stake sized by Kelly fraction, capped (default 2% of bankroll per bet).Project risk rule (no external source)
G-6No luck-only strategies: strategy must show positive expected value over the backtest window; variance-driven signals rejected.Project rule; computed from nfl_games.csv
G-7Every input cited: each input value carries a source link or is flagged unverified and left blank.This site’s verification standard
G-8Selectively skill-based: strategy restricted to setups where model probability exceeds market-implied probability by the gate threshold.Project rule; lines unverified

Leaderboard competition concept (not yet implemented)

  • Strategies are ranked by backtest expected value over the verified source window (G-2/G-3).
  • Top-performing strategies (passing all gates) receive rewards; no real-money component is part of this repository.
  • No manual input is required: signals are generated from the source data files automatically.
