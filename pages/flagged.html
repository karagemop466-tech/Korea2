Unverified values policy

  • If a value cannot be confirmed from a primary source, it is left blank.
  • A blank is always accompanied by a reason, on this page.
  • No value is inferred, interpolated or copied from a secondary summary.
  • Computed statistics are labelled as computations, with the code and data manifest that produced them.

Research and measurement, not betting advice. Every figure is computed by the code in this repository from the sources listed on the Source register page; nothing is estimated by hand.
