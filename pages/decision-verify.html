IR-01The 50.0% ATS coin-flip test is a tautology, not evidencedata/derived/luck.json reports n=13,784 and wins=6,892. 13,784 = 2 x 6,892: every game contributes one cover by the home side and one by the away side, so a pooled per-team-game cover rate is 50% by construction and the reported binomial p of 1.0 carries no information. The real, testable rate is the home-side cover rate, which the same extract puts at 0.4891 (3,371 of 6,892 decided games, two-sided p=0.073, normal approximation with continuity correction because n is 6,892).The site's 'the spread market shows no exploitable tilt' conclusion survives, but the quoted statistic behind it does not measure what it claims. Treat the p=1.0 as unverified.nflverse schedules (games.csv.gz) - spread_line, home_score, away_score
IR-02Two different 'our model' MAE numbers are published on different pagesREADME.md states the model spread MAE is 10.38 vs market 9.70; index.html and pages/lines.html state 10.391 vs 9.711. This module recomputes 10.391 vs 9.711 from data/derived/predictions.csv, which matches the site.README prose is stale against the committed data. The site is correct; the README should be updated by its owner.committed prediction file - 936 rows, 2023-2026
IR-03Committed data ends before the week the site is being read inThe schedules extract's latest gameday is 2026-11-01. The official NFL injury report for 2026 Week 10 (games of 12-15 November 2026) is already published, and its team records differ from the extract (e.g. the report shows NYG 5-2-1 and WAS 2-5-1; the extract, through 2026-11-01, resolves to NYG 4-2-1 and WAS 2-4-1 by its own convention). Any 'current slate' claim on the site is a snapshot, not live.Line origination for an unplayed week cannot be scored or compared to market using this extract. The pipeline must refresh before any decision that depends on this week.NFL.com official injury report, 2026 Week 10 - records printed on the page
IR-04Ties are silently excluded from the Pythagorean win totals16 regular-season games in the extract ended in a tie. The expected-wins model that produces the published R^2 counts only wins and losses (wins = count(margin > 0)), so tied games are scored as losses in the denominator but never as results. That does not change the headline conclusion but it does bias the luck decomposition by a few hundredths of a win per team-season.Minor. Document the convention before the luck decomposition is used to rank anything.nflverse schedules - result == 0
IR-05No historical player-prop prices exist in any committed sourcedata/derived/props.json evaluates prop *accuracy* (MAE) against realised box scores. There is no committed file containing a historical over/under price for a player prop, so no prop ROI, edge, or parlay price for props can be computed, and none should be displayed. The site says this; the leaderboard still lists 'player prop combos' as a family, which reads as if it had been tested.Any prop-family strategy must remain 'no price -> no result' until a licensed price source is committed.nflverse stats_player release - box scores only, no prices
IR-06Injury, depth-chart and snap-count feeds are published upstream but not committed herenflverse publishes `injuries_{season}`, `depth_charts_{season}` and `snap_counts_{season}` release assets for every season from 2015 to 2026. None of them is in this repository, and the sandbox this session runs in can reach only github.com/api.github.com, and the release assets themselves redirect to a host that is blocked, so the files cannot be ingested here. Every injury/depth claim in this repository is therefore either a description of the official report (checked by hand) or unverified.The injury and backup-depth requirement cannot be met from inside this environment. It needs a workflow run on GitHub-hosted runners that downloads those assets and commits the derived summaries, exactly as the existing data-pipeline does for schedules.nflverse-data releases: injuries, depth_charts, snap_counts (2015-2026)
IR-07Gate G1 (point-in-time integrity) cannot be satisfied by the current feedsG1 reads: 'Inputs are strictly pre-kickoff; no result-derived feature; source hashes recorded.'. The schedules extract carries a single `spread_line` per game with no timestamp saying when it was captured, and the injury/depth feeds that would date a lineup are not committed (IR-06). So the only point-in-time claim the pipeline can actually evidence is 'the line in the file'.Before any strategy is funded, the project needs a timestamped line capture and a timestamped lineup snapshot. No amount of modelling substitutes for that.gates_definition[G1] in strategies.json
IR-08Unfinished seasons are treated as complete team-seasons in the luck decompositionThe Pythagorean/luck table keeps every team with gp >= 8, which includes 2 partial team-seasons from the in-progress 2026 season (through 2026-11-01). Their expected wins are pro-rated by games played, so they do not bias the mean, but they do inflate the spread of actual win% and therefore move the reported R^2: with win% (published definition) it is 0.8191; if raw wins are used instead it is 0.8300. The published R^2 also uses win% while the persistence test uses raw luck wins, so the two rows of the luck table are not on the same scale.Report the luck decomposition on completed seasons only, or label 2026 as partial. The direction of every conclusion (luck does not persist) is unchanged.nflverse schedules - max gameday among played games = 2026-11-01
IR-09A cited official URL returns 404 (rulebook path changed)This session initially cited https://operations.nfl.com/the-rules/2026-nfl-rulebook/ for game-settlement context. That path returns the NFL's 404 page. The live path is https://operations.nfl.com/rules-officiating/2026-nfl-rulebook, which returns the 2026 rulebook and lists the four 2026 rule changes (6-1-3, 6-1-5, 6-1-6, 19-2). An earlier session already logged a 404 on the 2025 equivalent (IR/FL-09 in its register), so this is a recurring class of error in this repository, not a one-off.Every rulebook citation in the repository should be re-checked. A citation that 404s is not evidence, and the settlement rules (push, overtime, final score) matter for any backtest that uses them.NFL Football Operations - 2026 NFL Rulebook (live path verified 2026-11-12)
