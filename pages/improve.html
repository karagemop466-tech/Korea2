SITE IMPROVEMENTS — REVIEW QUEUE

Improve this site.
Choose the path first.

This section collects every proposal to make the site more useful for decision-making, with the trade-offs and one recommended path per proposal. Nothing here is implemented. A reviewer compares the options, picks a path, and only then does anything change.

How to review.
1. Read the proposal and the finding behind it (source column).
2. Compare the options and trade-offs with the recommended path in the worksheet below.
3. Record a decision per row — accept, modify, or reject — in COORDINATION.md or a GitHub issue. The row stays "awaiting reviewer" until a choice is recorded.

Those registers hold the evidence; this page is where the site itself gets better.

Research and measurement, not betting advice. Every figure is computed by the code in this repository from the sources listed on the Source register page; nothing is estimated by hand.
