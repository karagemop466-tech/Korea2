INJURY & DEPTH TRACKING

Who is missing, and how deep the drop is.

The brief asks the system to "track injuries and know any deficiencies in defenses such as 2nd, 3rd or 4th string backups having to replace starters." This page defines that detector, grounds it in official sources, and shows a verified Week 10 (2026) snapshot. Replacement-string depth is flagged where the official source is unavailable.

Official depth charts are not currently available from NFL.com.
The team /teams/<team>/depth-chart endpoint returns HTTP 404 (verified 2026-11-12), and the roster page does not expose depth ordering. So “starter vs 2nd/3rd/4th string” cannot be sourced officially yet. The injury report is available and is used as the verified layer; depth severity is flagged and a discovery path is given below.
Discovery →

How the deficiency detector works

  1. Pull the official injury report for the target week (league or team view) from NFL.com. This is the only injury layer verified to resolve today.
  2. Flag absences. Every player with Game Status OUT or QUESTIONABLE is a confirmed personnel loss; “Did Not Participate” with no game status is a watch item.
  3. Resolve the replacement’s string depth. Cross-reference the team’s verified depth chart to find whether the next man up is the 1st, 2nd, 3rd or 4th option. Flagged — official source unavailable (see above).
  4. Score the deficiency. Subtract replacement value from starter value to get a per-position drop. Flagged — requires a sourced player-value model, not yet present.
  5. Feed it to the model. Apply the deficiency as an adjustment to the originating ratings before lines are published.

Discovery suggestions (how to fill the gaps)

Depth / next-man-up

  • Use the nflverse team-depth extracts (third-party, not official — reconcile before use).
  • Use official Next Gen Stats snap counts as a proxy for who actually plays each position.
  • Track the weekly official injury report’s practice-status progression (Full → Limited → DNP → Out) as a leading indicator.
See flagged item →

Replacement value

  • Build a player-value model from verified box scores (source: official gamebooks / nflverse).
  • Express deficiency as starter value − replacement value, then as a points adjustment to the originating spread.
  • Validate the adjustment out-of-sample through the existing ten validation gates before any capital use.
