How sources are used

  • Official NFL documents define rules, statistics and data distribution.
  • Regulator filings define how bets settle, including pushes and parlay mechanics.
  • Academic work supplies the statistical methods (FDR control, bet sizing).
  • Community feeds supply the numbers, with file hashes recorded in the manifest.

Research and measurement, not betting advice. Every figure is computed by the code in this repository from the sources listed on the Source register page; nothing is estimated by hand.
