## 0. How this board works

1. A session claims a task by writing its **session ID**, **branch**, and **file scope** in the table
   below, then committing and pushing that claim immediately.
2. A session never starts a task that another session has claimed, unless the claim is **more than
   60 minutes old with no commits** (stale-claim takeover). Takeovers are logged in §5.
3. Scopes are non-overlapping. Each session works on its own branch named
   `session-<id>/<task>`. The Arena-tracked working branch for this session is
   `arena/6206fba3-korea2`; it is never renamed and never force-pushed.
4. If a task needs a change to a file owned by another session, the request is logged in §4
   instead of edited.
5. Shared outputs — `docs/data/*.json`, `docs/index.html`, `docs/assets/*`, and the site
   navigation — are only regenerated by the **final integration session** (§3, task T9/T10),
   once all other tasks are `done`.
6. `needs review` means the item is published on the site's **Flagged for Review** page and does
   **not** block integration.
