METHOD

How a strategy earns a rank

01Pre-register

The rule is fixed before any outcome is looked at, and it only sees pre-kickoff information.

02Walk forward

Each season is predicted using earlier seasons only. No shuffling, no future data.

03Price it

Settlement uses the stored closing price, not an assumed −110.

04Gate it

Six gates, including multiple-testing correction and a luck permutation test.

Luck cannot be removed from sport. It can be priced: every strategy here is compared against thousands of random portfolios of the same size, at the same prices.
