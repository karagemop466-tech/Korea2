Pricing note

Same-team legs must be priced with measured correlation (e.g., Gaussian copula calibrated to r=0.562, implied ρ≈0.60). Cross-game legs (different games) are approximately independent (r≈0). Player-prop combos need ex-ante WR assignments (depth-ranked), not ex-post game leaders (which inflate r by +0.24).

Sources: SRC-NIST-CORR · SRC-COLTS-DEPTH-CHART · SRC-DK-PARLAY-HELP

What this changes

  • Same-team QB→WR1 parlay at independent prices quotes ~2× too long.
  • Prop stacks using ex-post leaders inflate r by ~+0.24; need ex-ante depth-ranked assignments (SUG-03).
  • Cross-game legs approx independent (r≈0); compounded vig dominates unless each leg beats close.
