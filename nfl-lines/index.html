NFL Lines Origination — Dashboard

This site documents a program to originate NFL betting lines from first principles: single bets, parlays, and player-prop combinations, each passing validation gates, with correlation values measured and luck separated from skill. Every table row carries a source link for manual review; anything that cannot be confirmed from an official source is left blank and flagged as unverified.
