# Line Lab

A static GitHub Pages research dashboard for NFL forecasting methods, validation gates, and unresolved data gaps. Open `index.html` locally or visit the repository's GitHub Pages site. There are no dependencies or build steps.

The dashboard contains research proposals, not verified betting signals. No official outcomes or historical executable odds have been ingested, and no strategy has been backtested or approved. See the Flagged for Review page and `COORDINATION.md` for limitations and deployment status.

Run `python3 tests/check_site.py` to validate local links and ensure each table row has an official source link. The check cannot verify source claims, external availability, or deployment.
