Correlation Values

Correlations are measured from historical game results so parlay legs can be priced correctly (gate G-4). Values marked computed are project computations reproduced from the verified source file. Values marked unverified are left blank because the source does not contain the required data — never inferred or filled in.

Method notes

  • All computed values were generated by tools/empirical_correlations.py from data/raw/nfl-elo-game-master/data/nfl_games.csv and can be reproduced by running that script.
  • Correlation math: P(A and B) vs P(A)×P(B); correlation = (joint − independent) / sqrt(pA(1−pA)·pB(1−pB)).
  • Same-game and same-week correlations require data not present in the source file and are therefore blank/unverified.
