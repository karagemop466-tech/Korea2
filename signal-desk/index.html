1 · Price-snapshot store

There is no season in which this repository holds both an opening and a closing number. The opening file covers 2021-2021 only; the closing file stops at 2018. A per-bet open-to-close move, which is the number a demotion rule needs, therefore cannot be computed for any game from these two files together.

3 · Origination order

The published order does hold mechanically: the side is modelled first, the total is estimated from its own attack/defence terms, and the moneyline is Phi(side/sigma). What the order does not buy is accuracy - both originated markets are worse than the market closing line on the same games.

Where to start

  1. Questions — twelve questions that each block at least one decision. Several cannot be answered from data at all; they need a choice from you.
  2. Suggestions — eight proposals, each with impact, effort, risk and the question it waits on. None is implemented.
  3. Flagged for review — every irregularity and every unverified cell, with the source link, so you can check it yourself.
Research and measurement, not betting advice. Every number on this page is rendered from signal-desk/data/*.json; none is typed by hand. A blank cell means the value could not be confirmed from the source named in that row — it is never inferred.
Official figures are transcribed from nfl.com pages read on the date shown in each row. Third-party figures come from nflverse community data and are labelled as such.
