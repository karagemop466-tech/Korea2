The headline problem

There is no season in which this repository holds both an opening and a closing number. The opening file covers 2021 only; the closing file stops at 2018. A per-bet open-to-close move, which is the number a demotion rule needs, therefore cannot be computed for any game from these two files together.

What the store records, and what it cannot

A snapshot is recorded only where a named source publishes the number.
