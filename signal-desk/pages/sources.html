How a source earns the word official

Official means the page was opened and read on 2026-11-14 and the values were transcribed into signal-desk/scripts/transcripts.py. Everything else is third-party, including nflverse, which is a community project and not the league.

Reproduce it

Four commands

python signal-desk/scripts/fetch_prices.py then python signal-desk/scripts/analysis.py then python signal-desk/scripts/build.py then python signal-desk/scripts/check.py. The analysis step imports scipy directly and does not reuse the repository's own statistics helpers, so it cannot agree with them by construction.

Research and measurement, not betting advice. Every number on this page is rendered from signal-desk/data/*.json; none is typed by hand. A blank cell means the value could not be confirmed from the source named in that row — it is never inferred.
Official figures are transcribed from nfl.com pages read on 2026-11-14; every source is listed on the Sources page. Third-party figures come from nflverse community data and are labelled as such.
