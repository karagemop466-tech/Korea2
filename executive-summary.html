Executive Summary — NFL Lines Origination Program

Prepared 2026-11-01 • Repo: karagemop466-tech/Korea2 (branch arena/dda090fd-korea2) • Status: initial build, all line/odds values unverified

1. Objective

Originate NFL betting lines from first principles rather than copying market prices. Generate useful signals for single bets, parlays, and player-prop combinations; run the program like a leaderboard competition that rewards top-performing strategies; remove luck and keep only selectively skill-based setups.

2. Approach

  • Data: historical NFL game results (scores, dates, teams, Elo win probabilities) from the verified source file covering 1920–2020 seasons (16,810 games).
  • Signals: model-implied probabilities (Elo) compared against market-implied probabilities from betting lines; edges above a threshold are candidate bets.
  • Bet types: single bets (moneyline), parlays (2–3 legs with correlation adjustment), player-prop combos.
  • Validation gates: G-1 edge after vig, G-2 minimum sample (≥100 games), G-3 out-of-sample check, G-4 correlation disclosure, G-5 bankroll/Kelly cap, G-6 no luck-only signals, G-7 sourced inputs, G-8 skill-selectivity.
  • No manual input: all signals generated from the source data files.

5. Key findings

  • Home teams won 53.82% of regular-season games 2018–2020; home favorites won 62.93%. These are reproducible project computations from the verified source.
  • No official NFL betting lines exist: the NFL does not publish odds. Every line/odds field in this program is blank and unverified until a sportsbook data source is added and reviewed.
  • Player-prop data and same-week schedules are absent from the source file; same-game and same-week correlations cannot be measured yet.
  • All six strategy templates fail to be "verified" today solely because lines/odds are unverified — not because the logic is flawed. Gate G-7 blocks promotion until sources exist.

6. Recommendations

  • Add a sportsbook odds source (e.g., DraftKings/FanDuel/Caesars published lines) and mark those pages with their own source links; re-run gate G-1.
  • Add play-by-play and schedule data to enable same-game and same-week correlation measurement (flags F-04, F-05).
  • Add team-to-division mapping for divisional correlation (flag F-06).
  • Implement the leaderboard: rank strategies by backtest expected value over the verified window; reward top performers.
  • Review all items on the Flagged for Review page before any real-money use.
