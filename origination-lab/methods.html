Methods and reproducibility

How every number on this site is produced, settled and tested — with the code path that regenerates it.

Pipeline

scripts/fetch_data.py     # pull 9 extracts, hash them, write data/manifest.json
scripts/build_integrity.py # 9 checks: signs, reconciliation, coherence, coverage
scripts/build_lines.py    # walk-forward rating model -> spread / total / moneyline
scripts/build_signals.py  # 27 specified signals, FDR + out-of-sample
scripts/build_strategies.py # 18 strategy families, 7 gates, leaderboard
scripts/build_props.py    # player prop origination + calibration
scripts/build_correlations.py # phi coefficients, copula pricing, key numbers
scripts/build_luck.py     # permutation nulls, reliability, evidence bar
scripts/build_site.py     # this site
scripts/check_links.py    # internal links + external source links

python3 scripts/build_all.py runs the lot in dependency order. No step requires network access except fetch_data.py.

The rating model

Points scored is modelled as an additive function of team offence, opponent defence, a home-field constant and a rest differential, fitted by weighted ridge regression on the stacked home and away equations. Weights decay with a 1.15-year half-life. For every (season, week) block the fit uses only games that kicked off earlier; the block is then predicted. Ratings carried into a new season are shrunk 40% toward league average. Franchise relocations are mapped to one code (F10).

  • Spread = predicted home margin, rounded to the nearest half point.
  • Total = sum of the two predicted scores, rounded to the nearest half point.
  • Moneyline = Φ(margin / 13.6). The 13.6-point sigma is the residual scale of NFL margins.

Settlement rules

  • Every bet is 1 unit and settles at the American price recorded in the source extract.
  • Push → stake returned, zero profit, excluded from the hit-rate denominator.
  • Parlay price = product of the leg decimal prices, expressed back as American odds.
  • Parlay with a pushed leg → whole ticket treated as a push (conservative; F5).
  • Teaser → fixed two-team price of −110 (assumption; F4).
  • Returns are never compounded and no stake sizing is applied.

Statistics

  • Break-even test: one-sided exact binomial against the win rate implied by the prices actually taken (not against 50%).
  • Wilson intervals for every hit rate.
  • Benjamini-Hochberg false-discovery control across the whole research programme (45 tests).
  • Max-statistic block bootstrap (4-week blocks) for the best-of-N correction.
  • Permutation null for team-season ATS dispersion, preserving the one-winner-per-game constraint.
  • Bootstrap confidence intervals for strategy ROI.
  • Brier score and log loss for probability forecasts.
  • Phi coefficient with a Fisher-z interval for binary leg correlation.

Discovery / validation split

Signals and strategies are developed on 2002-2015 (discovery) and judged on 2016-2026 (validation). Gate G2 uses the full sample for power, because discarding half the data makes a real 2% edge effectively invisible; the untouched window is then required to agree in sign and to be positive.

Reproducing any number on this site

  1. python3 scripts/fetch_data.py — downloads and hashes the extracts; compare against data/manifest.json.
  2. python3 scripts/build_all.py — rebuilds every JSON artefact and the site.
  3. Every published figure is a field in data/derived/*.json; the site renders those files directly, so a discrepancy means a stale build, never a hand-edited page.

Limitations

  • Closing prices from a single undocumented source (F1); no line shopping, no live or prop markets.
  • No injury, roster, practice or travel data; weather fields are undocumented (F13).
  • Player-week data covers two seasons only (F2).
  • League-official verification is a spot check, not an automated diff (F7).
  • Results are historical and in-sample to the sport, not a forecast of any future season.

Not betting advice

This is a research artefact. Nothing here is a recommendation to place a wager, and the project's own conclusion is that none of its strategies has yet demonstrated an edge that survives validation.
