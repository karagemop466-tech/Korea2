Methods

The exact formulas, windows and thresholds, so the work can be checked or rebuilt without reading the code first. Code: pipeline/.

Line origination

Points-scored model, two rows per game:

home_points = μ + hfa·1[home] + attack[home] + defence[away]
away_points = μ              + attack[away] + defence[home]

minimise  Σ w_i (y_i − x_iβ)²  +  α Σ β_j²   over the attack and defence coefficients only
w_i = 0.5 ^ (age_in_days / 200)      refit for every (season, week)
α   = 5    (selected on 1999-2014 only, see the origination page)

Own spread = home_points − away_points. Own total = home_points + away_points. Own moneyline = Φ(margin / σ) where σ is the recency-weighted residual standard deviation of the training window, floored at 10 points.

No-lookahead contract. A fit for week W uses only games with a gameday before that week's first kickoff. The contract is tested by recomputing pre-game Elo for 2024-2026 from prior games only and comparing to the stored values: 842 games (2024-2026) recomputed from prior games only; 0 mismatches.

Bet settlement

  • Spread: bet wins if margin − line is positive for a home bet, negative for an away bet; equal is a push.
  • Total: over wins if points − line > 0, under wins if < 0, equal is a push.
  • Moneyline: a tie is a push.
  • P&L: one unit staked; win pays decimal − 1, loss pays −1, push pays 0.
  • Parlay: leg decimal prices multiplied; all legs must win, any push voids.

Gates

  • G4 bootstrap. 10,000 percentile resamples of per-ticket P&L; the 2.5th percentile is the statistic that must exceed zero.
  • G5 permutation. For each ticket, the null win probability is the market's de-vigged probability for that side. 20,000 simulated tournaments; p is the share whose ROI is at least the observed ROI.
  • G6 Benjamini-Hochberg. Applied to the G5 p-values of all strategies; q < 0.10 required.
  • G7 deflated Sharpe. Bailey & López de Prado (2014), non-annualised per-bet Sharpe, deflator built from the number of trials with the Euler–Mascheroni approximation to the expected maximum.
  • G8 calibration. Brier score of our model probability versus the market's de-vigged probability on exactly the same tickets.
  • G9/G10 stability. 60% of seasons with at least 20 tickets must be positive, and both halves of the evaluation window must be positive.

Prop models

Ridge regression per market, trained on all seasons strictly before the season being predicted, with a minimum of two training seasons. Features: last-3 mean, last-5 mean, season-to-date mean, career games, home/away, the team's market-implied total, and the opponent's exponentially-weighted yards allowed to that position group. Reference line for grading: trailing five-game mean, rounded to the half point. Naive probability: the base over-rate measured on training seasons only. Anytime touchdown has no line, so it is compared against the position-group base rate.

Reproducing

python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python pipeline/fetch_data.py        # pinned downloads + hashes
python pipeline/fetch_data.py --check
python pipeline/run_all.py           # features → models → gates → props → correlation → verify → site

Runtime on a laptop-class machine: about five minutes. The ridge refit loop dominates.
