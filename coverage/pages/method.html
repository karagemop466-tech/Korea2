METHOD

How this audit is computed.

No number here is typed by hand. The audit is a deterministic Python standard-library script that parses every HTML page and measures the rule; the dashboard is rendered from its JSON.

MEASURES

What is measured

The full audit is reproducible from the committed script and data.
CheckDefinitionSource
Per-row sourceA table row is sourced when its last cell contains an <a href>.Page coverage
Row countstbody rows are counted per page; thead cells are excluded.Page coverage
Link integrityInternal links are resolved against the file tree; external links must be https.Link integrity
Tier / categoryEach page is classified by its directory and generator stamp.Overview
Legacy policyArchive pages are read-only; unsourced rows are reported and flagged, never rewritten.Legacy review
REPRODUCE

Reproduce it

python3 coverage/scripts/audit_coverage.py
python3 coverage/scripts/build_site.py

The audit reads files only. It writes coverage/data/coverage.json and the rendered pages in this directory. It touches no audited file. The audit excludes its own coverage/ output directory, so it is deterministic and not self-referential; the repository-wide link check still validates these pages.
