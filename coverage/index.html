DEFINITION

The rule being measured

A table row is sourced when its last cell contains a link. A row is unsourced when it has no link. The audit never edits an audited file; unsourced rows on legacy archives are published on the Legacy review page so a reviewer can act on them. Computed values are labelled as computed and are not presented as official data.
