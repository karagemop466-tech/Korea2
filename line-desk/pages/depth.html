Policy

Track the DEPTH of a replacement, not just the fact that one is needed. Injury facts come from the official report. Replacement identity and string tier (starter / 2nd / 3rd / 4th) stay blank unless an official source states them - and none does: the report has no depth column and the league depth-chart path 404s.

A depth-deficiency signal (starter out, replacement is 2nd string or deeper) cannot be computed until replacement_string is sourced; it stays an unmeasured requirement, not a proxy.

Blocked: No official depth chart exists to source replacement identity or string tier from: the NFL.com team depth-chart path returns HTTP 404 (checked first-hand 2026-11-14), and the official injury report carries no depth-rank column. Checked: depth-chart path returned HTTP 404 on 2026-11-14.
