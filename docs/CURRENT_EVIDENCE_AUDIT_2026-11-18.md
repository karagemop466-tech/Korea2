# Current evidence audit — 2026-11-18

## Executive summary

This is a narrowly scoped, read-only audit of the committed repository plus a fresh check of selected official NFL pages. It is **not** a fresh line-by-line re-verification of every claim or row in every hub. The full project still lacks the primary evidence needed to approve a wagering strategy: a permitted and complete time-stamped market-price archive, one canonical official-results corpus, a durable point-in-time availability history, and prospectively frozen strategy runs. The repository's validators pass, but they establish internal consistency and link discipline—not predictive skill, source freshness, or profitability. No candidate should be treated as approved for live betting.

## Suggestions to review before implementation

These are proposals, not approved changes. The existing [Suggestions register](../pages/suggestions.html) and [decision questions register](../pages/decision-questions.html) remain the review surfaces. The current review register should be updated with the following discovered source issue:

1. **Replace the stale generic Game Book citation.** Fresh retrieval of the cited `operations.nfl.com/.../official-game-book/` path returned 404, while the official NFL.com game-centre page exposed a game-specific Game Book PDF. Replace the generic link with the game-centre route and retain the per-game PDF as evidence. Add a check that follows the Download Game Book link for sample games.
2. **Set a Game Book terms gate.** The PDF contains a reuse restriction. Do not broaden row-level public ingestion until written permission/terms are addressed; ask NFL data-licensing counsel/contact to confirm allowed capture, storage, derived use and publication.
3. **Add immutable snapshots outside the static-site repository.** Daily injury report, transactions, club source and official Game Book captures need source/time/hash/parser metadata, conflict flags, access controls, freshness alarms and replay by as-of time. Do not claim immutable snapshots based on a rendered page fetch without retaining bytes.
4. **Reconcile the canonical outcomes feed and price policy.** Choose one game ID, official result evidence policy, price-source license and missing-price settlement rule before further backtest publication. The 136-game corpus must be frozen as a preregistered dataset rather than silently expanded after outcomes.
5. **Keep personnel modelling blocked until evidence is complete.** No jersey-order/salary/experience inference. Record expected starter, announced starter, actual Game Book starter, inactive, measured snaps (only if a permitted official feed is found), and roster event as distinct evidence with timestamps.
6. **Apply prospective skill gates before prizes.** Singles-only shadow baseline first; then benchmark-relative Brier skill, clustered uncertainty and multiplicity control. Parlays/props stay unranked until a joint-probability and settlement gate clears. A demotion gate returns live strategies to paper if prospective skill deteriorates.
7. **Protect site trust.** Keep the landing-page readiness matrix with one requirement per row, blocking gate, clearing number/test, as-of time and official source. Keep source/status distinctions visible; the site checker reports 33 non-root pages without the root table-source column, so those pages require a dedicated provenance sweep.
